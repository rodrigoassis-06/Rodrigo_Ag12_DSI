## 📋 Descrição do Projeto

Desenvolvimento de uma página web completa para armazenar e apresentar sites favoritos, utilizando HTML5 semântico e estilização CSS moderna.

### Requisitos Atendidos:
- [x] **Título na aba do navegador (`<title>`):** `Meus sites favoritos`
- [x] **Título no corpo da página (`<h1>`):** `Meus sites favoritos: Rodrigo Assis`
- [x] **5 sites favoritos catalogados:**
  1. Centro Paula Souza (Portal de Ensino Tecnológico)
  2. YouTube (Vídeos e Aprendizado)
  3. GitHub (Hospedagem de Código e Projetos)
  4. Google (Buscador Web)
  5. Stack Overflow (Comunidade de Desenvolvedores)
- [x] **Estrutura por site:**
  - Nome do site acima de cada imagem (`<h2>`)
  - Imagem local do site (`<img>`)
  - Fonte da imagem indicada
  - Link clicável abaixo da imagem (`<a>`)
  - Link configurado também na própria imagem (recurso opcional cumprido)
- [x] Código HTML ricamente comentado linha a linha.
- [x] Capturas de tela incluídas no projeto:
  - `captura_execucao_navegador.png` (Execução da página no navegador)
  - `captura_codigo_comentado.png` (Trecho do código com comentários explicativos)

---

## 🚀 Como Visualizar a Página

1. Abra o arquivo `index.html` ou `Rodrigo_Ag12_DSI.html` diretamente em qualquer navegador (Google Chrome, Microsoft Edge, Firefox, etc.).
